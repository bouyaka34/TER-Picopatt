# Analyse exploratoire

Ce dossier regroupe les notebooks de prise en main des données PICOPATT :

- `Analyse_exploratoire.ipynb` : distributions, corrélations, profils par parcours et comparaisons par créneau.
- `NoZero.ipynb` : traitement des zéros et préparation des données nettoyées.
- `Localisation.ipynb` : travail sur les coordonnées et les éléments spatiaux.
- `Clustering.ipynb` : essais de regroupement et comparaison de profils.
- `agreg.ipynb` : agrégations par passage, parcours ou créneau.

Ce travail a été réalisé lors du semestre 1.
