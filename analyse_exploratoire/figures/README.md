# Figures d'analyse exploratoire

Ce dossier contient les figures utilisées pour l'analyse exploratoire du semestre 1.

La plupart proviennent de la branche `Figures` et sont maintenant rangées directement dans ce dossier. Le rapport S1 pointe directement vers ces fichiers, sans dupliquer les graphiques dans `rapport/s1/`.

Les figures qui n'avaient pas d'équivalent clair dans la branche `Figures` ont été rangées par thème :

- `comptage/presence_passages/` : présence des passages par date et créneau.
- `correlation/par_mslot/` : matrices de corrélation par parcours et par créneau.
- `controle_qualite/` : contrôles des valeurs aberrantes et de la cohérence physique.
- `profil/profils_temps/` : profils moyens de température utilisés dans le rapport.
