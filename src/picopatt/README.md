# Package `picopatt`

Ce dossier regroupe les fonctions Python partagées entre les notebooks et les scripts.

- `io.py` : lecture des fichiers PICOPATT et création de dossiers.
- `cleaning.py` : normalisation des noms de parcours, dates et créneaux.
- `features.py` : statistiques descriptives et moyenne circulaire.
- `alphaearth.py` : réservé aux fonctions AlphaEarth qui seront factorisées plus tard.
- `modeling.py` : réservé aux fonctions de modélisation qui seront factorisées plus tard.
- `mapping.py` : réservé aux fonctions de cartographie qui seront factorisées plus tard.
