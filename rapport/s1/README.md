# Rapport du semestre 1

Ce dossier contient le rapport consacré au nettoyage, à la structuration et à
l'analyse exploratoire des mesures PICOPATT.

## Contenu

- `Rapport_TER_PICOPATT.tex` : source LaTeX
- `Rapport_TER_PICOPATT.pdf` : version PDF
- `references.bib` : bibliographie
- `Images/` : logos, photographies et figures utilisées dans le rapport
- `out/Rapport_TER_PICOPATT.pdf` : sortie de compilation conservée

Le rapport du semestre 1 constitue le point de départ du travail prédictif du
semestre 2. Il décrit notamment les parcours, les variables mesurées, les
opérations de nettoyage et les premiers profils spatio-temporels.
